This document lists the frontend's API usage as it exists in the repository. It is grouped by unique endpoint and notes the files that call each endpoint, the request shape used in code, and the response fields that are read back in the frontend.

## Notes On Shape Consistency

- No contradictory request payload shapes were found for the repeated endpoints in the inspected files.
- `POST /auth/login` consistently uses `{ email, password }`.
- `POST /support/messages` consistently sends the form fields plus `role`.
- The main inconsistency visible in the codebase is not an endpoint shape problem: `src/hooks/useSocketToast.js` reads `VITE_API_SOCKET_URL` while the setup docs also mention `VITE_SOCKET_URL`.

## Scope Note

This document covers the endpoint surfaces requested in the task: `src/api/`, Redux thunks in `src/store/slices/`, and direct component/page axios calls. Hook-level axios usage can be added in a follow-up appendix if you want the inventory expanded further.
